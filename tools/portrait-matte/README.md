# Portrait matte tool

Deterministic, allowlisted chroma-key processing for the six locked Su Ming raw
references. It uses the installed `sharp` package only; it does not download,
generate, segment, resize, or reinterpret the character.

## Inputs and outputs

The input allowlist is fixed in `config.mjs`:

- `packages/content/characters/suming/refs/base.jpg`
- `packages/content/characters/suming/refs/{shame,panic,lonely,tempted,uncanny}-raw.jpg`

Runtime output is limited to the matching stable filenames under
`apps/web/public/assets/portraits/`. For inspection, `--out-dir` writes the same
six filenames to a caller-selected local evidence directory.

## Commands

```bash
node tools/portrait-matte/process.mjs --write-runtime
node tools/portrait-matte/process.mjs --out-dir .devspace-visual/portrait-matte/candidate
node tools/portrait-matte/calibrate.mjs --report .devspace-visual/portrait-matte/calibration.json
node tools/portrait-matte/gate.mjs
node tools/portrait-matte/verify.mjs
```

`process.mjs` requires exactly one output mode. `calibrate.mjs` reproduces the
raw-key and accepted-control evidence behind the thresholds. `gate.mjs` checks
all eight official Su Ming runtime portraits, including subject connectivity,
enclosed transparent holes, coverage, probes, dimensions, and edge spill.
`verify.mjs` proves two-pass byte/hash determinism, proves the runtime bytes are
the generated bytes, and proves that an opaque-magenta fixture is rejected.

The matte and gate parameters, together with their calibration notes, are
versioned in `config.mjs`.
